# ADR-0066: 语义熵分歧度量——k=5 跨族 + 聚簇 + 底噪扣减 + 交叉质询

- status: accepted（2026-08-22）
- deciders: 人（owner randypanding）+ AI
- 关联: 宪法 §4E（生产者红队：spec 红队）/§9#9；.github#220（W4-C1）；
  外部范式：Semantic Entropy 双向蕴含聚簇（Kuhn/Gal/Farquhar 等，Nature 2024）、
  LM vs LM 交叉质询、MAST 14 模式检查表、Cognition 干净上下文实证

## 背景

散文 spec 的歧义只有一个暴露途径：不同的实现者对同一份 spec 派生出不同的
系统。单个实现者对自己的解读永远自洽——歧义测不出来。宪法 §4E 生产者红队
第一项即 spec 红队：k 路跨族独立重派生后度量语义分歧，分歧显著即 spec 有
歧义。铁律：**分歧绝不退化为投票**（不是数票选多数派），而是聚簇定位+
质询归因。卡 #220 触发。度量方法站在 Semantic Entropy（Nature 2024）肩上：
双向蕴含聚簇替代"表面字符串相似度"，语义等价的措辞差异不误报。

## 决策

1. **k=5 跨族冷上下文独立重派生**：5 路派生者分属不同模型族（k 路输入
   带族标记，各族≥1 路——AC-4 断言），在干净上下文（不带任何先前实现
   残留，Cognition 实证：污染上下文掩盖分歧）各自从 spec 派生实现要点/
   接口契约/边界行为，互相不可见。
2. **双向蕴含聚簇**：对 5 路输出两两做双向蕴含判定（NLI 模型 DeBERTa-MNLI
   或等效，版本钉死入 registry）；A↔B 互蕴含归同簇；输出簇集。语义聚簇
   生效=措辞差异不误报（AC-1）。
3. **簇数/熵判定=零 LLM 确定性脚本（AC-4）**：簇数与语义熵的计算是纯
   脚本，判定阈值入 contract.yaml；LLM 只在派生与质询环节。
4. **底噪扣减（AC-2）**：同族模型同提示重采样测自分歧基线 B（模型固有
   随机性噪声）；仅**跨族簇数−B≥2** 才归因 spec 歧义——把模型噪声误报成
   spec 问题会摧毁红队公信力。
5. **交叉质询定位（AC-1/AC-3）**：超阈值触发 LM vs LM 交叉质询——各簇
   代表互问"你对条款 X 的理解与依据"，输出**引用 spec 原文的结构化不一致
   陈述+条款 ID 坐标**；质询轮次硬上限（默认 3 轮）防成本失控；歧义类型
   按 MAST 14 模式检查表标注归因。
6. **运行位置**：spec PR 阶段 + 波次收口（非每 commit——5 路派生成本高）；
   报告落 archive 红队报告区（§13 推论二飞轮原料）。

## 后果

- 正面：歧义在实现前暴露且定位到条款坐标，红队报告可直接喂回 spec 修订；
  底噪扣减+语义聚簇双保险压误报。
- 负面/代价：每次度量=5 路 LLM 派生+NLI 两两判定，成本与时长显著；
  只覆盖 spec 阶段，实现期引入的歧义由波次红队（k 路独立分解一致性）接力。
- 风险与缓解：NLI 蕴含判定误差 → 模型钉版+人工抽检校准；分歧度量被
  Goodhart（spec 写成法条规避质询）→ 阈值与句型要求（ADR-0060）协同。
- 回滚：红队 workflow 可整体摘除（不阻断主流程，纯报告产物）；NLI 模型
  与派生者档案在 registry 可替换。
