# ADR-0072: verifier 入职考试 CI + 校准集循环 + AI 可读性 rubric shadow

- status: accepted（2026-08-22）
- deciders: 人（owner randypanding）+ AI
- 关联: 宪法 §4C（T2 持证上岗制）/§5（veto 先 shadow）/§13 推论三（模型
  无关）；.github#226（W5-C3）；外部范式：LLM-as-a-Verifier
  （arXiv:2607.05391 + 同名开源项目）、RewardBench2/LLMBar（考试集）、
  敏感度/特异度校准（arXiv:2511.21140，ICML'26）、G-Eval（arXiv:2303.16634）、
  MT-Bench 位置交换（arXiv:2306.05685）、null-model 攻击实证
  （arXiv:2410.07137）（宪法 §9 署名规则 #3）

## 背景

T2 层用 LLM verifier 按 rubric 判定，但 LLM judge 不经考试与校准就上岗=
用未校准的裁判执法——位置偏差、空响应讨好、对抗样本崩塌都会伪装成
"判定"。宪法 §4C 立持证上岗制：入职考试（CI 关卡）+ 出分即校准 +
veto-only。W5-C3 把考试、校准循环与第一个 verifier（AI 可读性 rubric）
落成实装。模型无关条款（§13 推论三）：考试对一切判定者候选生效——
provider 模型、未来自训练小模型一视同仁。

## 决策

1. **冻结考试集**：RewardBench2 生成式赛道 + LLMBar 对抗子集 + ≥20 条
   null-model 金丝雀（空响应/模板复读必须判负——100% 判负，AC-2）+
   成对样本双序（位置交换一致率 ≥0.90，AC 覆盖）。考试集冻结存档于
   archive `evalsets/`，版本化。
2. **入职考试 CI（AC-1）**：新 judge/模型候选必须考试集全过才注册进
   agent-registry（registry 条目带考试成绩引用）；任一子集不过即拒上岗；
   成绩按 `judge_id@版本@prompt_hash` 存档——模型换代或 prompt 改动即
   重考（档案可追溯）。
3. **校准集循环（AC-3）**：owner 的 merge/reject 动作自动成为校准样本
   （零额外操作——宪法 §4C"一定是静默完成的"）；维护 100-200 条人类
   裁决；owner 确认比例 ≥20%；估计敏感度/特异度。
4. **出分即校准（AC-3）**：T2 出分=校正值±置信区间（连续分，禁离散
   印象分）；**CI 下界低于及格线 → 自动升人类**（不猜、不静默放行）。
5. **AI 可读性 rubric shadow（AC-4）**：五判据=可定位性（从 AGENTS.md/
   index 找到符号的容易度）/入口清晰度（index 出口是否准确反映能力）/
   模块深度充分性（接口是否真把复杂度挡在门内）/命名词表一致性/示例
   文档新鲜度；每判据判据分解+每档锚定描述（rubric 契约另行成文）；
   **先 shadow：出分仅记录不阻断**；shadow 达标升 veto 走 §5 晋升。
6. **标注负债申报**：每个 T2 verifier 申报年度标注人力预算（入 registry
   条目），未配预算不许从 T3 迁移——负债是永久性的（§10.4），申报制
   控数量。
7. **对抗防御（自研薄层）**：输入隔离（被评内容不进 judge 指令通道）、
   模板封装、异构多 judge 分歧即升级（宪法 §4C）。

## 后果

- 正面：judge 质量从假设变考试档案；校准集随真实裁决静默增长（飞轮）；
  校正分+CI 下界让"裁判不确定"显式可见。
- 负面/代价：考试与校准是持续性成本；标注负债永久（模型换代即重标，
  §10.4 诚实接受）。
- 风险与缓解：考试集泄漏/过拟合 → 冻结+版本化+金丝雀轮换（owner 月度
  补给）；校准集分布漂移 → 敏感度/特异度按窗口重估。
- 回滚：未过考试的 verifier 不存在执法面——摘除考试 CI 即回"无 T2
  执法"世界（T1 确定性关卡不受影响）；rubric shadow 本身零阻断。
