# ADR-0107: 体系层级声明——理论层与实施层的关系（吸收并利用）

- status: accepted（2026-09-06）
- deciders: 人（owner randypanding——DGA-ADJUDICATION v1.0 §1，2026-09-06 发布即签署，S-1）+ AI（现场编码 agent 转录入档）
- 关联: DGA 文档族 v1.0/v1.0.1（理论层 SSOT）；宪法 v2.4（实施层正本，正文零改动）；
  ADR-0103 决策 6（总纲吸收先例——方向相反：总纲为操作性文件故分散吸收，DGA 保留
  整体形态因其价值在推导链）；IR-0009 卡 A3（本 ADR 为其交付件）

## 背景

DGA 文档族五份（理论 2 + 实例 3）经 S5 裁决成为组织的理论层与原则层 SSOT。原有全部
治理文档（宪法 v2.4、GOVERNANCE.yaml、policy/ 11 件、ADR 序列、各仓 AGENTS.md）与
理论层的关系需要正式声明，否则双 SSOT（ADR-0103 决策 6 已确立防双 SSOT 原则）。

## 决策

文档层级三层，权威单向：

| 层 | 文档 | 地位 | 修改纪律 |
|---|---|---|---|
| 理论层 | DGA / DGA-A / DGA-STRATEGY / DGA-MIGRATION / DGA-TOOLING | 原则与形态学 SSOT | 理论版本纪律（版本号递增+理由记录+禁止静默修改） |
| 实施层 | 宪法 v2.4、GOVERNANCE、policy/、ADR 序列 | 运行时执法机制 | ADR 流程 |
| 工作层 | 各仓 spec、卡、ROLE-*.md、AGENTS.md | 具体工作物 | 仓内流程 |

**吸收并利用的四条语义**：

1. **吸收**：实施层条目逐条映射入 DGA 框架（absorption map，方向=实施层条目→理论层
   条目，IR-0009 卡 A2 产出）。映射完成后，实施层机制的权威来源=DGA 对应条款+本 ADR；
2. **利用**：运行中的执法机制全额继续生效，不重写、不废弃——它们是 DGA 形态学的活的
   实例化且已实弹验证（部分严于 DGA 目标：判定物有效性自检、fail-closed 缺席即停）。
   重写运行中的执法机制违反验证经济学（已验证资产弃置=验证成本浪费）；
3. **冲突处理**：实施层与理论层冲突 → STRAT §8.3 断裂协议二选一。举证责任在偏离方：
   任何偏离 DGA 条款的实施层机制，必须以"合法实例采样"身份登记（参数差异+理由+登记
   位置=absorption map 采样偏离条目）；未登记的偏离按理论层修正；
4. **新决策的推导顺序**：理论上从 DGA 出发 → 实例化落在实施层（新 ADR/机制/政策）。
   实施层新增机制必须在 absorption map 上可回链。

**冲突消解次序**（同级冲突取更严格者，DGA-A §1）：理论层 > 实施层 > 工作层 > 临时指令；
临时指令永不解除理论层绝对禁令（DGA-A §11 N-10 对应）。

## 后果

- 正面：理论-实例双 SSOT 风险消除；DGA 文档族的 git 外状态（自指矛盾，宪法 §14c
  "凡不能写进 Git 声明的就不能被输出"）由 IR-0009 卡 A1 入库关闭；
- 代价：absorption map 的建立与保鲜成为新治理负担（卡 A2 首建，drift 对账延伸待后续）；
- 宪法正文零改动——层级关系由本 ADR+absorption map 承载（宪法修改是昂贵仪式，本声明
  不需要它）。
